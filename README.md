# Optical-Hygrometer
This repository contains all the files for the creation and programming of the optical hygrometer and data analysis.

The 3D part files are provided in both .3mf format for printing and .f3d format for further development.

Any ESP32 code used in this project was included, much of it is likely unnecessary.

The HITRAN data used is not provided as the file would be too big to upload.
